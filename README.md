# Banking System

> Sistema bancário via terminal desenvolvido em Java.
> Status: em desenvolvimento.

## Sobre o projeto

O **Banking System** será uma aplicação interativa de terminal que simula operações bancárias. A proposta é modelar clientes, contas e transações, aplicando regras de negócio semelhantes às de um sistema financeiro real.

Além da aplicação, este projeto é um espaço de prática contínua para consolidar fundamentos de Java, Programação Orientada a Objetos e Git.

## Funcionalidades planejadas

- Cadastro e gerenciamento de clientes;
- Criação de contas corrente e poupança;
- Depósitos, saques, transferências e consulta de saldo;
- Histórico de transações;
- Menu interativo no terminal;
- Validação de dados de cadastro;
- Tratamento de erros, como saldo insuficiente;
- Organização das regras de negócio em uma arquitetura clara e modular.

## Conceitos que serão aplicados

- Encapsulamento;
- Herança;
- Polimorfismo;
- Abstração e classes abstratas;
- Interfaces;
- Collections (`List`, `ArrayList` e `Map`);
- Tratamento de exceções;
- Organização em packages;
- Boas práticas de código;
- Versionamento com Git e GitHub.

## Estrutura planejada

```text
br.com.banco
│
├── Main.java
├── model/       # Entidades do domínio: Client, Account e Transaction
├── service/     # Regras de negócio e gerenciamento do banco
├── util/        # Componentes de apoio, como o menu
└── exception/   # Exceções personalizadas
```
