# Banking System

Sistema bancário desenvolvido em **Java**, com interface via terminal.

> **Status:** 🚧 Em desenvolvimento

## Sobre o projeto

O **Banking System** é um projeto de estudo desenvolvido para simular o funcionamento de um banco digital por meio de uma aplicação em terminal.

O principal objetivo é aplicar conceitos de **Programação Orientada a Objetos (POO)**, modelando entidades e regras de negócio presentes em sistemas financeiros reais.

Este projeto será evoluído continuamente, acompanhando minha jornada de aprendizado em Java e no desenvolvimento backend, incorporando novas funcionalidades, padrões de projeto e tecnologias utilizadas no mercado.

---

## Objetivos

- Praticar Programação Orientada a Objetos
- Desenvolver uma arquitetura organizada e modular
